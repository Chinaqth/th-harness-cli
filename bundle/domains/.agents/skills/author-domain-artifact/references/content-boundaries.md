# Content Boundaries

Keep durable professional practice in the Domain Pack. Keep product paths, repository commands,
architecture facts, customer context, deployment environments, temporary objectives, and stricter
local constraints in project overlays or task contracts.

Never add credentials, production data, customer data, undocumented permissions, invented owner
decisions, or rules that weaken Kernel security, privacy, authorization, or evidence requirements.

When a professional claim lacks an authoritative source, preserve the gap as `needs_input`.
