# Web Prepare

Execute only when the Kernel dispatches this Domain stage. Preserve the dispatch context_id and invocation ID in the receipt. The host calls the Skill; the Kernel supplies no professional implementation.

Identify frontend semantics, accessibility target, browser/support matrix, HTTP/privacy boundaries and observable acceptance criteria. Inspect the existing frontend and supplied design inputs.

Form a concrete plan and acceptance criteria from user intent. Record unresolved inputs and safe assumptions; do not add a Kernel plan-confirmation pause. Return artifacts, issues, assumptions and next_actions.

Return status completed, partial, unavailable or error. Preserve actual evidence and platform/user authority. Ordinary quality failures are recorded and do not prevent lifecycle evaluation and summary.

Read the Domain professional reference `workflows/PROFESSIONAL_PROCEDURE.md` and selected capability rules on demand. It supplies technical criteria, not a Kernel execution gate.
