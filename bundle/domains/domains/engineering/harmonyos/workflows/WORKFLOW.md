# HarmonyOS Lifecycle Implementation

Implements Kernel 4.0 through lifecycle.json: prepare, execute, evaluate, summarize.
Professional capability catalogs and technical rules remain authoritative. The stage
Skills select and compose the declared professional Skills for each capability.

No Kernel approval checkpoint or whole-flow quality gate applies. Missing tools,
inputs or evidence become issues; dependent operations may remain unperformed while
other feasible work continues. Missing authority is never an implicit grant.
Evaluation runs independently and summarizes actual coverage. Bounded repairs return
to execution and reevaluation; final summary distinguishes achievement from flow end.
