# Protocol Versions

Kernel protocol 4.0, Routing Plan 5.0, lifecycle 1.0, Task Envelope 2.0. Existing Domain catalog schemas retain 1.0; lifecycle bindings use their own 1.0 schema. Compatibility explicitly requires Kernel 4.0 for Web 2.0.0 and HarmonyOS 7.0.0. Protocol-3 approvals cannot resume protocol-4 tasks. Start a new task record.

Development snapshots are identified by SHA-256 over authoritative source files and marked development in the Runtime manifest. They are not committed release revisions. Release builds require clean sources and matching committed pins. Development builds require explicit --development and never forge release provenance.
