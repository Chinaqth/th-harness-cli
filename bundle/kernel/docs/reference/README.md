# Reference Sources

Files in this directory preserve authoritative source material used to design the workstation.

## Language Handling

- Keep source material verbatim and identify its locale in the filename.
- Write architecture, governance, rules, Skills, agent instructions, and other derived operational guidance in English.
- Cite the relevant source when a derived rule depends on a specific claim.
- Do not silently translate or rewrite an authoritative source because doing so would weaken provenance.
